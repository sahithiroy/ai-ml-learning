Two developers (let's say Alice and Bob) are working on the same branch (e.g., feature-branch).

Alice pushes her changes first to the remote.

Bob has not pulled Alice's changes yet, and he commits his own local changes.

When Bob tries to push, Git blocks it because his local branch is behind the remote.
