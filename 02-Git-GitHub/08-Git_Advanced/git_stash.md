# Git Stash

## What is it?
Git stash temporarily saves your local changes without committing them.

## When to use it
Use stash when you need to switch tasks quickly without losing your current work.

## Common commands
- `git stash` to save changes
- `git stash list` to view stashes
- `git stash pop` to restore the most recent stash

## Scenario
- You are halfway through a feature but must fix an urgent bug on another branch.
- You want to keep your current edits safe before switching branches.
