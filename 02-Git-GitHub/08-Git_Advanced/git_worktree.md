# Git Worktree

## What is it?
Git worktree lets you check out multiple branches in separate working directories at the same time.

## Why it is useful
It is helpful when you need to work on two branches at once without switching your main working folder.

## Scenario
- You are fixing a bug in one branch while reviewing a feature in another.
- A developer needs to test a hotfix without disturbing their current worktree.
