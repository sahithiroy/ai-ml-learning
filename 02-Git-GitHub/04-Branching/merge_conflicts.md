# Merge Conflicts

Merge conflicts happen when Git cannot automatically combine changes from two branches.
'You change same code
        +
Teammate changes same code
        ↓
git merge
        ↓
Git cannot decide
        ↓
MERGE CONFLICT
        ↓
You manually choose/fix code
        ↓
git add
        ↓
git commit
        ↓
Merge completed'
