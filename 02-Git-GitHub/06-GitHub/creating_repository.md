# Creating a Repository

## What is it?
A repository, or repo, is the main storage place for a project on GitHub. It contains your files, commit history, branches, and collaboration tools.

## What you do
1. Go to GitHub and click New repository.
2. Choose a name, visibility, and optional README.
3. Create the repository.
4. Connect it to your local project with Git commands such as `git remote add origin <url>` and `git push -u origin main`.

## Why it is useful
A repository helps you keep your code organized, share it with others, and track every change over time.

## Scenario
- You are building a portfolio website and want a central place to store all your code online.
- Your team is starting a new project and needs a shared space for the source code.
