# Issues

## What is it?
Issues are GitHub items used to track bugs, tasks, feature requests, or questions related to a project.

## Why they are useful
They give the team a shared place to describe problems and plan improvements.

## Common usage
- Report a bug
- Suggest a feature
- Assign work to a teammate
- Add labels such as bug, enhancement, or help wanted

## Scenario
- A user reports that the website crashes when they submit a form.
- A team wants to collect ideas for the next release and creates several issues for discussion.
