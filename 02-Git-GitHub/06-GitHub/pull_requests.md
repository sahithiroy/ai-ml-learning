# Pull Requests

## What is it?
A pull request is a request to merge your changes from one branch into another. It is the main way teams review and discuss code before it is accepted.

## Why pull requests are important
They help teammates review changes, leave comments, and catch problems before the code reaches the main branch.

## Typical workflow
1. Create a branch for your work.
2. Commit your changes.
3. Push the branch to GitHub.
4. Open a pull request.
5. Review, discuss, and merge when approved.

## Scenario
- A developer adds a new login page and opens a pull request for team review.
- A student fixes a bug in a project and asks the instructor to review the change.
