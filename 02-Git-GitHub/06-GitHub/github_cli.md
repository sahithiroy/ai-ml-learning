# GitHub CLI

## What is it?
GitHub CLI lets you manage GitHub from the terminal with commands like `gh`.

## Common commands
- `gh repo create` to create a repository
- `gh pr create` to open a pull request
- `gh issue create` to report an issue

## Scenario
- A developer creates a repo and opens a pull request directly from the terminal.
- A student manages issues and pull requests faster without leaving the command line.
