# Repository Structure

## What is it?
A repository structure is the way a project is organized inside GitHub. It usually includes source files, documentation, branches, and project management features.

## Common parts of a GitHub repository
- README: explains the project
- LICENSE: defines how the code can be used
- .gitignore: ignores files that should not be committed
- Branches: separate lines of development
- Issues, pull requests, and releases: support collaboration and delivery

## Why it matters
A good structure makes it easier to understand the project, onboard new contributors, and manage changes safely.

## Scenario
- A student repo contains Python exercises in one folder, notes in another, and a README with instructions.
- A company project uses separate branches for development, testing, and production.
