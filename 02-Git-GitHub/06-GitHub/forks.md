# Forks

## What is it?
A fork is your own copy of another person’s repository on GitHub. It lets you experiment, make changes, and submit them back without affecting the original project.

## When to use it
Use a fork when you want to contribute to open-source projects or test ideas safely.

## Typical workflow
1. Fork the repository on GitHub.
2. Clone your fork to your local machine.
3. Create a new branch.
4. Make changes and push them.
5. Open a pull request to suggest the update.

## Scenario
- You want to fix a bug in an open-source library you use in your project.
- You want to try a new feature in someone else’s project without changing their main code.
