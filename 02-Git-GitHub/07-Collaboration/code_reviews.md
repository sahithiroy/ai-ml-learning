# Code Reviews

## What is it?
Code review is the process of checking another person’s changes before they are merged.

## What reviewers look for
- Correctness
- Readability
- Bugs or edge cases
- Style and consistency

## Why it is useful
Code reviews improve quality, share knowledge, and help the team learn from each other.

## Scenario
- A teammate reviews your new feature and suggests improving a function before it is merged.
- A project leader checks a pull request to ensure the new code follows team standards.
