# Resolving Conflicts

## What is it?
Conflicts happen when two people change the same part of a file and Git cannot automatically decide which change to keep.

## How to resolve them
1. Open the conflicted file.
2. Review the markers added by Git.
3. Choose the correct version or combine both changes.
4. Save the file.
5. Stage and commit the resolved result.

## Why it matters
Conflict resolution helps you safely combine work from different contributors.

## Scenario
- Two teammates edit the same section of a README file at the same time.
- A developer updates a function while another person fixes a bug in the same block of code.
