# Collaboration Workflow

## What is it?
A collaboration workflow is the process a team follows to work together on a project using Git and GitHub.

## Typical steps
1. Create a branch for your task.
2. Make changes and commit them.
3. Push the branch to GitHub.
4. Open a pull request.
5. Review, discuss, and merge the changes.

## Why it matters
A clear workflow helps avoid confusion, makes code review easier, and keeps the main branch stable.

## Scenario
- A team is building a web app and each member works on a separate feature branch.
- A student and instructor review code changes before merging them into the main project.
