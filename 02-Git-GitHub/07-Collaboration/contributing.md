# Contributing to a Project

## What is it?
Contributing means helping improve a project by making changes, reporting issues, or suggesting ideas.

## Common ways to contribute
- Fix a bug
- Add a feature
- Improve documentation
- Review pull requests

## Why it matters
Contributing helps open-source and team projects grow and improves collaboration.

## Scenario
- A student fixes a typo in an open-source README file.
- A developer adds a small feature to a shared project and submits it for review.
